# Telegram Bot for Teachers 📚🤖

A smart Telegram bot designed to help teachers manage schedules, share educational materials, and automate communication with students.

## ✨ Key Features
* **Automated Scheduling:** Quick access to the class timetable for teachers and students.
* **Homework & Material Distribution:** Send home assignments and study files in one click.
* **Student Notification System:** Broadcast important announcements to all students instantly.
* **FAQ Automation:** Auto-replies to frequently asked questions from students.
