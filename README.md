## Teacher Web & Telegram Platform 📚💻🤖

A complete ecosystem including a responsive web dashboard and a Telegram bot, designed to help teachers manage schedules, distribute educational materials, and automate communication with students.

## ✨ Key Features
* **Teacher Web Dashboard:** A convenient web interface for instructors to manage materials, update schedules, and track student progress.
* **Automated Telegram Bot:** A fast mobile assistant for students and teachers to access real-time timetables and receive instant notifications.
* **Homework & Material Distribution:** Upload files via the website and deliver them instantly to students via Telegram.
